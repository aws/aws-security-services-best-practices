# 추가 참고 자료

이 섹션은 핵심 가이드 섹션에 포함되지 않는 보충 참고 자료를 포함합니다. 여기의 주제는 주요 WAF 모범 사례 지침에 부수적이며 시간이 지남에 따라 확장될 수 있습니다.

## WAF Classic과의 알려진 차이점

이 하위 섹션은 의도적으로 최소화되어 있습니다. AWS WAF(이전의 "AWS WAFv2")는 서비스의 현재 버전이며 이 가이드의 유일한 초점입니다. 아래 정보는 이전에 AWS WAF Classic을 사용했던 고객이 알려진 동작 차이점을 인식할 수 있도록 간략한 참조로 제공됩니다.

!!! note "이것은 마이그레이션 가이드가 아닙니다"
    이 섹션에는 단계별 마이그레이션 지침이 포함되어 있지 않습니다. 전체 마이그레이션 지침은 공식 AWS 문서를 참조하세요:
    [AWS WAF Classic 리소스를 AWS WAF로 마이그레이션](https://docs.aws.amazon.com/waf/latest/developerguide/waf-migrating-from-classic.html).

*고객 참여 및 운영 경험을 통해 식별되는 구체적인 차이점이 이 섹션에 문서화됩니다.*
