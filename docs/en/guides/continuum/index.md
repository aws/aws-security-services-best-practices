# AWS Continuum best practices

[AWS Continuum](https://docs.aws.amazon.com/continuum/latest/userguide/what-is-continuum.html) helps identify, validate, and address application security risks. Choose the guide for the capability you want to configure.

| Capability | Where to start |
|---|---|
| Code vulnerabilities | [Connect source code, add AWS context, run scans, and review issues and patches](code-vulnerabilities/index.md). |
| On-demand penetration testing | [Configure and run penetration tests](../security-agent/index.md). |
| Threat modeling | Follow the [AWS threat modeling documentation](https://docs.aws.amazon.com/securityagent/latest/userguide/perform-threat-model.html). |

Each capability has its own setup and access requirements. Use the documentation linked from its guide when choosing permissions, integrations, and data protection settings.
